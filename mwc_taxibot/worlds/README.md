# Mundos de simulación

Este directorio incluye `mwc_pavilion.world`, un mundo Gazebo sencillo con paredes, zonas y marcadores de color.

La implementación actual no fuerza un robot concreto. Puede integrarse con TurtleBot, Kobuki u otra base móvil siempre que publique los topics estándar de navegación y tenga un servidor `move_base` activo.
