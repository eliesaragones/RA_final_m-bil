# Mapas

Este directorio está preparado para guardar el mapa del entorno MWC TaxiBot.

Archivos esperados en una práctica completa con ROS Navigation:

- `mwc_pavilion.yaml`: metadatos del mapa.
- `mwc_pavilion.pgm`: ocupación del entorno.

El paquete ya define las zonas lógicas en `config/zones.yaml`. El mapa real o simulado debe usar el mismo sistema de referencia `map`.
